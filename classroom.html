Deploying on GitHub Pages

This virtual classroom is 100% static (HTML, JS, CSS) and requires zero server-side code. You can host it completely free on GitHub Pages:

  1. Create or open your GitHub repo (e.g., cosylanguages).
  2. Add this classroom.html file to the root of your repository.
  3. Go to Settings > Pages in your GitHub repository.
  4. Select the main branch and click Save.
  5. Your app will be live at https://yourusername.github.io/cosylanguages/classroom.html!

How PeerJS Real-time Sync Works:

PeerJS connects both browsers directly via WebRTC data channels using a free public signaling server (0.peerjs.com). No backend installation required!
