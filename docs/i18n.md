# COSYplatform Internationalisation (i18n) Documentation

## Overview

COSYplatform uses a lightweight client-side internationalisation engine (`shared/js/i18n.js`) backed by flat JSON key-value dictionaries stored in `shared/i18n/`.

Supported UI languages:
- **`en`**: English (Source / Reference Locale)
- **`fr`**: French (Français)
- **`ru`**: Russian (Русский)
- **`it`**: Italian (Italiano)
- **`el`**: Greek (Ελληνικά)

---

## Language Resolution Order

When resolving the active UI language, `CosyI18n` evaluates rules in the following strict order (first match wins):

1. **Pinned choice**: `localStorage.getItem("cosy_ui_lang")` (must be a supported code like `en`, `fr`, `ru`, `it`, `el`).
2. **URL override**: `?ui=<code>` query parameter (supported code or `"pseudo"`). Applies to the current page load only and is **never** persisted.
3. **Context language**: `?lang=<code>` parameter, or the language of the course specified in `?course=<id>` (looked up from `CosyAuth.FULL_MANIFEST`). Used only when no language choice is pinned.
4. **Profile default**: The first supported code in `profile.language_access` (skipping `"*"` and unsupported codes).
5. **Browser language**: Primary subtag of `navigator.languages` (e.g. `'fr'` from `'fr-FR'`), if supported.
6. **Fallback**: `"en"`.

### First Paint Caching

The resolved language is cached in `localStorage.getItem("cosy_ui_lang_last")` (not a pin). On initial page load before the user profile is fetched, `cosy_ui_lang_last` is used for immediate rendering. Once Supabase returns the user profile, `CosyI18n.recompute(profile)` re-evaluates language rules and re-applies translations if the language changed.

When logging in on `login.html`, successful sign-in updates `cosy_ui_lang_last` before redirecting to the user's workspace.

## Dictionary Structure & Key Naming

Dictionaries are stored in `shared/i18n/{code}.json` as flat JSON objects.

Keys are namespaced by page or component domain:
- `common.*`: Shared buttons, labels, counts, and status indicators.
- `login.*`: Login portal title, labels, error banner messages, and placeholders.
- `notfound.*`: 404 page headings and action links.
- `index.*`: Public course catalog headings, search filters, and slide preview labels.
- `hub.*`: Unified hub portal titles and section headings.
- `founder.*`: Founder portal stats, admin panel headers, and space buttons.
- `footer.*`: Ecosystem footer links and strip captions.
- `switcher.*`: Language switcher aria-labels and options.

### Metadata Block (`_meta`)

Every dictionary file includes a top-level `_meta` block:
```json
{
  "_meta": {
    "status": "ai-draft",
    "reviewedBy": null
  }
}
```
For `en.json`, `status` is set to `"source"`. For translated files, initial AI-generated drafts are set to `"ai-draft"`.

## Placeholders & Plurals

### Interpolation Placeholders
Placeholders are defined in string values as `{variableName}`:
```json
"common.userLabel": "User: {email}"
```
Usage in JS: `CosyI18n.t('common.userLabel', { email: 'teacher@domain.com' })`

### Plurals
Plurals use suffix keys (`.one`, `.few`, `.many`, `.other`) selected via `Intl.PluralRules`:
```json
"common.lessons.one": "{count} lesson",
"common.lessons.few": "{count} lessons",
"common.lessons.many": "{count} lessons",
"common.lessons.other": "{count} lessons"
```
Usage in JS: `CosyI18n.tp('common.lessons', 5)`

## DOM Translation Attributes

`CosyI18n.applyDom()` automatically translates elements matching the following data attributes:

- **`data-i18n="key"`**: Sets `textContent = t(key)` (or updates `<title>` to `t(key) + " · COSYlanguages"`).
- **`data-i18n-count="N"`**: Evaluates plural `tp(key, N)`.
- **`data-i18n-placeholder="key"`**: Sets element `placeholder = t(key)`.
- **`data-i18n-title="key"`**: Sets element `title = t(key)`.
- **`data-i18n-aria="key"`**: Sets element `aria-label = t(key)`.
- **`data-i18n-skip`**: Exempts dynamic content (e.g. course titles, user emails, UUIDs) from translation checks.

## Workflow: Native Teacher Review Process

1. **AI-Drafting**: Initial translations are generated with `_meta.status = "ai-draft"`.
2. **Review**: A native-speaking language teacher inspects the translations for naturalness, tone, and accuracy.
3. **Formal Tone**: Wording must use natural UI language for a language school and employ formal/polite forms (`vous` / `вы` / `Lei` / `εσείς`).
4. **Approval**: Upon review, the teacher updates `_meta` in `{lang}.json`:
   ```json
   "_meta": {
     "status": "reviewed",
     "reviewedBy": "Teacher Name <teacher@cosylanguages.com>"
   }
   ```
5. **Report**: Running `npm run i18n:report` displays review status and key coverage across all supported languages.
