# General English A0 / A1 Curriculum Crosswalk: COSYplatform vs COSYlanguages

## Executive Summary

This crosswalk maps every lesson slot in COSYplatform's **General English A0** (`curriculums/general-english-a0.json`) and **General English A1** (`curriculums/general-english-a1.json`) to the corresponding source lesson in COSYlanguages' **A1 General Curriculum** (`curriculums/en/general/A1.json`).

* **COSYplatform Skeleton**: 20 units (8 units in A0 + 12 units in A1), totaling 109 lesson slots (including orientation slots, core lessons, optional expansion lessons, progress tests, midterm/final exams, and feedback sessions).
* **COSYlanguages Source**: 10 units (50 lessons total, 5 lessons per unit).
* **Mapping Dynamics**: Because COSYplatform provides a significantly more granular pedagogical structure (109 slots vs 50 lessons), mapping is predominantly **many-to-one**. COSYplatform splits foundational topics (e.g. greetings, family, daily routine, food, housing) into dedicated, highly focused micro-lessons.
* **Content Gaps**: COSYplatform contains several units and specialized topics not directly covered in COSYlanguages' 50-lesson A1 file. These content gaps (e.g., orientation/meta-lessons, progress tests/exams, weather/seasons/zoo, health/medical advice, clothing/fashion, corporate culture, advanced shopping/online retail) are explicitly flagged as **[CONTENT GAP - PHASE 2 ORIGINAL]**.
