# COSYplatform — repository notes

## Layout
- `curriculums/<lang>/<track>/<LEVEL>.json` — the source of truth for a course: `units[].lessons[]`,
  each lesson carrying `title`, `grammar`, `grammarIds`, `vocabulary` and a `teacher_notes` string
  whose `code: "FR-B1-001"` is the key used by the lesson generators.
- `roadmaps/<course-id>.json` — `sequence[]` with `lessonNumber`, `id`, `unit`, `status`, `lessonFile`.
- `lessons/<course-folder>/*.json` — one deck per lesson, ten slides, stages warm-up → cool-down.
- `shared/js/auth-guard.js` — `window.CosyAuth.FULL_MANIFEST`; a course with
  `"status":"not_yet_available"` is hidden and excluded from the stats.
- `data/platform-stats.json` — generated by `npm run stats:build`; counts courses and lesson slots
  that are in the manifest and referenced by a roadmap.

## Commands
```bash
npm run validate     # content integrity checks
npm run stats:build  # regenerate data/platform-stats.json
```

## Lesson generation
`/tmp/cosy_build.py` holds the shared `Spec` class: it writes the ten-slide deck from a per-lesson
dict (`cando`, `chunks`, `reading`, `listen`, `pron`, `adapt`, `practice`, `rule`, `prior`, `next`,
`hw`) plus a glossary of the curriculum vocabulary. `/tmp/fr_b1_spec.py` configures it for French B1
and resolves `fr-b1-*` grammar ids to the COSYmanuals B1 topic files.

Every lesson needs two grammar links, or slide 5 loses its `grammar-focus` element. Units 10 to 12
of the French B1 curriculum shipped with `grammarIds: null`; they were filled in by hand.
