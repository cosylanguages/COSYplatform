# Reference Manuals & Teacher Guides

This directory acts as the reference portal linking COSYplatform to teacher guides, onboarding manuals, and pedagogical resources hosted in `COSYmanuals`.

> ⚠️ **COSYmanuals Deep-Link Structure Assumption**:
> As specified in platform migration documentation, content in `COSYmanuals` follows the standard public URL structure: `https://cosylanguages.github.io/COSYmanuals/teacher-guides/` and `https://cosylanguages.github.io/COSYmanuals/curriculums/{iso}/{course_type}/{level}.json`.
> **Flagged for Founder Confirmation**: If COSYmanuals is deployed under a different domain or path structure, update `base_url` in reference configurations accordingly.
